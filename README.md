# Methane Action Desk

Independent experimental tracker for follow-up on satellite methane detections in Türkiye.

Website: https://methane-action-desk.vercel.app

Status: No methane reductions verified by this project yet. Observed plume rates must not be interpreted as continuous or annual emissions.

Initial research: https://law.ucla.edu/news/spotlight-top-methane-sources-turkeys-waste-sector
